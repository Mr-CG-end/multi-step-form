# Page Agent 模块二：演示界面与交互计划

## 1. 模块职责

本模块负责访客能够看到和操作的 AI 演示界面，包括浮动入口、首次同意说明、预设指令、自由输入、运行状态和三语言文案。界面必须继承项目现有的 Ubuntu 字体、深蓝文字、淡紫背景和圆角节奏，不把页面改造成通用聊天产品，也不复制 Page Agent 原生面板。

本模块依赖模块一提供的 `usePageAgentDemo()`。在该接口完成前可以搭建静态界面，但不得自行操作 `window.pageAgent` 或复制一套加载逻辑。

## 2. 文件范围

本模块独占以下文件：

- 新建 `src/components/PageAgentDemo.vue`
- 更新 `src/App.vue`
- 新建 `src/i18n/locales/zh-CN/agent.ts`
- 新建 `src/i18n/locales/zh-TW/agent.ts`
- 新建 `src/i18n/locales/en/agent.ts`
- 更新三套语言的 `index.ts` 入口

不得修改 Page Agent 运行时文件、Step 组件、Store、`package.json` 或部署配置。

## 3. 页面结构

`PageAgentDemo.vue` 由一个浮动按钮和一个可收起侧边面板组成。桌面端面板固定在右下区域，宽度控制在 340 至 380 像素；移动端改为底部抽屉，最大高度不超过可视区的 70%。浮动按钮不能与现有语言切换器、下一步按钮或确认按钮重叠。

面板包含以下区域：

- 标题“AI 表单演示”和一句简短说明。
- 三个示例指令按钮。
- 自由输入文本框与 300 字计数。
- 主操作按钮；运行时切换为停止按钮。
- 当前状态和简短结果提示。
- 测试 API 与虚构数据说明链接或折叠说明。

不增加完整聊天记录、头像气泡、消息时间戳或多轮会话列表。这个项目要展示的是 Agent 操作页面，而不是聊天 UI 本身。

## 4. 首次启用说明

首次打开时，在面板内部展示同意页，不使用阻断整个网站的全屏弹窗。说明必须清楚表达：

- 这是非生产技术演示。
- 任务指令和简化页面结构会发送到官方测试服务。
- 不允许输入真实姓名、邮箱、手机号或其他敏感信息。
- 演示使用固定虚构资料，测试服务可能限流或停止。

按钮为“同意并开始演示”和“暂不使用”。同意状态只保存在当前浏览器的 `localStorage`，key 使用 `multi-step-form-page-agent-consent`；版本值设为 `1`，便于条款变化后重新征求同意。拒绝后关闭面板，不加载 CDN，不影响普通表单。

## 5. 示例指令与自由输入

三条预设指令在不同语言下表达相同业务含义：

1. 选择年度专业版，不添加附加服务。
2. 选择月度基础版，添加在线服务和自定义个人资料。
3. 选择年度高级版，添加更大存储空间。

点击预设指令后直接调用 `execute()`。自由输入 placeholder 明确写“只描述套餐、计费周期和附加服务，请勿填写个人信息”。输入为空时执行按钮不可用；运行中锁定预设按钮和输入框，避免状态竞争。

运行状态使用简短、可翻译的文本：正在加载 AI、正在操作表单、已到达汇总页、任务已停止、服务暂时不可用。错误提示不展示原始网络响应或接口信息。

## 6. 与现有页面的集成

在 `App.vue` 中将 `PageAgentDemo` 与 `LanguageSwitcher` 放在同一应用级层级，AI 面板不能嵌入某个 Step，否则步骤切换会卸载运行中的控件。

组件通过 `useI18n()` 获取 `locale` 和文案。调用 `load()`、`execute()` 时传入当前 locale；繁体中文的可见 UI 仍使用繁体语言包，Agent 工作语言由模块一映射。

组件卸载时只清理自己的事件和临时 UI 状态，不擅自清除用户已经完成的普通表单。Page Agent 实例的释放统一调用模块一的 `dispose()`。

## 7. 可访问性与响应式要求

- 浮动入口使用真实 `button`，具有 `aria-expanded` 和 `aria-controls`。
- 面板使用有名称的补充区域，标题与内容建立关联。
- 示例指令、同意、关闭、执行和停止都必须可通过键盘触发。
- 运行状态使用 `aria-live="polite"`；阻断性错误使用 `role="alert"`。
- 焦点打开后进入面板，关闭后返回浮动入口；Esc 可关闭空闲面板，运行中 Esc 不停止任务。
- 移动端输入框弹出键盘后仍能看到执行或停止按钮。
- 遵守 `prefers-reduced-motion`，只保留必要的淡入和位移动效。

## 8. 视觉验收

- 面板与现有表单属于同一视觉系统，不使用渐变霓虹、玻璃拟态大面积背景或过多阴影。
- 桌面宽度 1440、1024，以及移动宽度 375、390 下都没有遮挡核心操作。
- 面板打开和关闭不会改变表单主体宽度，不引起页面跳动。
- 三种语言切换后没有截断、重叠或明显宽度溢出。
- AI 执行期间 Page Agent 自带的元素高亮可以显示，但原生面板保持隐藏。

## 9. 功能验收与交付

- 未同意时不调用 `load()`；同意后只加载一次。
- 三个示例按钮传递的偏好文本与语言正确。
- 自由输入的校验错误能在组件内清楚展示。
- 运行期间可以停止，完成或失败后可以再次执行。
- Page Agent 不可用时，关闭面板后普通表单操作完全正常。
- 运行 lint、生产构建，并对桌面与移动布局进行截图检查。

交付说明附上桌面和移动截图、三语言截图、所使用的运行时接口，以及任何需要集成 Agent 处理的冲突。不要修改其他模块文件来顺手解决冲突。
